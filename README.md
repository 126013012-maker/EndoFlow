# EndoFlow – A Guideline-Driven CDSS for Endocrine Disorder Diagnosis

EndoFlow is a team-developed, web-based Clinical Decision Support System created as part of the BIN400 Project Work & Viva Voce (2025–26 Even Semester) at SASTRA Deemed University.

Developed using PHP and JavaScript, it is designed as an educational tool to help medical students understand endocrine differential diagnosis through clinical guideline-based logic.

### My Individual Contributions – Deeksha R
- Designed the user interface for clinical inputs and diagnosis display.
- Implemented a weighted diagnostic scoring algorithm.

### Key Learning
- Encoding Endocrine Society guidelines into rule-based diagnostic logic.
- Developing dynamic JavaScript interfaces with real-time scoring.


**Note:** EndoFlow is an educational project and is not intended to replace professional medical diagnosis.
