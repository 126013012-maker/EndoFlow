# EndoFlow – A Guideline-Driven CDSS for Endocrine Disorder Diagnosis

## Project Overview

EndoFlow is a team-developed, web-based Clinical Decision Support System (CDSS) designed as an educational tool to help medical students understand endocrine differential diagnosis using clinical guidelines.

Developed as part of the B.Tech Bioinformatics final-year project at SASTRA Deemed University.

## Key Features

- Covers 26 endocrine disorders across 6 endocrine systems.
- Includes 96 clinical symptoms across 9 functional categories.
- Integrates 43 laboratory parameters.
- Uses weighted symptom matching and laboratory assessment.
- Generates ranked differential diagnosis suggestions.
- Displays matched and missing symptoms.
- Provides emergency alerts and ICD-10 mapping.
