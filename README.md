# EndoFlow – A Guideline-Driven CDSS for Endocrine Disorder Diagnosis

## Project Overview

EndoFlow is a team-developed, web-based Clinical Decision Support System (CDSS) designed as an educational tool to help medical students understand endocrine differential diagnosis using clinical guidelines.

Developed as part of the B.Tech Bioinformatics final-year project at SASTRA Deemed University.

## Project Objectives

- To develop an educational tool for understanding endocrine disorders.
- To organise clinical symptoms and laboratory parameters based on endocrine clinical guidelines.
- To support structured differential diagnosis through weighted symptom and laboratory matching.
- To present relevant clinical information in a user-friendly interface.

## Key Features

- Covers 26 endocrine disorders across 6 endocrine systems.
- Includes 96 clinical symptoms across 9 functional categories.
- Integrates 43 laboratory parameters.
- Uses weighted symptom matching and laboratory assessment.
- Generates ranked differential diagnosis suggestions.
- Displays matched and missing symptoms.
- Provides emergency alerts for selected conditions.
- Includes ICD-10 mapping and clinical information.

## Project Workflow

1. Enter patient demographic details.
2. Select the presenting clinical symptoms.
3. Review the suggested priority laboratory tests.
4. Enter the available laboratory values.
5. Analyse symptom and laboratory matches.
6. View ranked differential diagnosis results with matching scores and relevant clinical information.

## How to Run the Project

1. Install and open WAMP Server.
2. Download or clone this repository.
3. Copy the `endoflow_v6` project folder into the WAMP `www` directory.
4. Start the Apache server.
5. Open your browser.
6. Access the application using:

   `http://localhost/endoflow_v6/`

Note: Local setup may require checking the project configuration before running.
